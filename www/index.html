Identitas toko & struk

Logo toko

Background header

🔒 Kolom identitas toko, teks struk, tema, PIN, dan logo disembunyikan di HP ini. Semuanya hanya diatur di HP Utama (Kode HP = 1), lalu otomatis menyebar ke HP ini. Pengaturan printer, kertas, dan nama kasir tetap bisa diubah di sini.

Pembaca barcode

Scan memakai kamera HP: di halaman Kasir pilih ikon 📷 lalu tekan tombol scan. Saat pertama kali, modul scanner Google diunduh otomatis (butuh internet sekali). Scanner Bluetooth mode keyboard juga tetap bisa dipakai.

Scanner USB atau Bluetooth mode keyboard (HID) cukup dicolok, atau dipasangkan lewat Windows (Settings → Bluetooth & devices); tidak ada pairing di aplikasi. Di halaman Kasir hasil scan langsung menambah barang. Scanner mode serial/COM dihubungkan di bawah.

Printer struk

Printer Bluetooth: (1) pasangkan printer di Pengaturan Bluetooth HP; (2) pasang aplikasi RawBT dari Play Store, buka, lalu pilih printer tersebut di dalamnya; (3) di sini pilih "Bluetooth HP (lewat aplikasi RawBT)", tekan Hubungkan printer, lalu Cetak tes dan Simpan pengaturan. Saat mencetak, RawBT akan terbuka sebentar.

Printer Bluetooth: pasangkan dulu di Windows, ia akan muncul sebagai port COM. Mode langsung butuh Chrome/Edge. Printer USB biasa dengan driver Windows paling mudah lewat "Driver Windows"; USB langsung butuh driver WinUSB. Klik Simpan pengaturan untuk menyimpan pilihan.

Sinkronisasi antar HP (Firebase)

Catatan: HP Utama = Kode HP 1 (yang datanya paling lengkap/benar). Hubungkan HP Utama LEBIH DULU: ia mengunggah semua data ke cloud sebagai patokan. HP kedua dst. diisi Project ID, API Key, email, dan password yang sama, tetapi Kode HP berbeda (2, 3, ...). Data di HP kedua dst. akan DIGANTI data cloud, dan HP kode 2 dst. tidak bisa mengunggah bila cloud masih kosong. Identitas toko/struk/PIN/logo hanya bisa diubah di HP Utama. Saat internet atau listrik mati, transaksi tetap tersimpan di HP dan terkirim otomatis begitu online. Ikon ☁ di pojok atas = tersinkron, ⚠ = ada yang menunggu/bermasalah. Lisensi aplikasi tetap per HP. Hapus transaksi dan backup/pulihkan sebaiknya hanya dilakukan di satu HP.

Cadangan data (terenkripsi)

File backup dienkripsi AES-256-GCM dengan kata sandi backup. Jika kata sandi hilang, backup tidak bisa dibuka dan tidak ada cara memulihkannya. Catat di tempat aman.

Cara pakai:
1. Isi email akun Google yang dipakai di HP ini, lalu pastikan aplikasi Google Drive sudah terpasang dan login dengan akun itu.
2. Tekan Backup ke Google Drive. File backup dibuat otomatis, lalu menu bagikan Android terbuka.
3. Pilih Drive (Simpan ke Drive), pastikan akun sesuai email di atas, lalu tekan Simpan.
Di komputer: file backup terunduh otomatis dan halaman Google Drive terbuka, tinggal tarik file ke Drive.
Login Google (email + sandi) tidak bisa diotomatisasi oleh aplikasi lain, jadi login dilakukan sekali di aplikasi Drive. Sandi sengaja tidak disimpan di sini karena ikut terbawa di dalam file backup.

Data tersimpan di penyimpanan lokal aplikasi/browser di perangkat ini (offline); data di APK, aplikasi komputer, dan browser TIDAK saling terhubung. Buat backup rutin, terutama sebelum ganti HP, menghapus data aplikasi/browser, memasang ulang, atau Update harga (.mdb).

Backup otomatis terjadwal

Backup berjalan selama aplikasi terbuka; jika aplikasi sedang tertutup, backup yang terlewat dijalankan begitu aplikasi dibuka lagi. File disimpan terenkripsi di folder POS-Backup (Android: Dokumen; komputer: Dokumen). Backup di HP yang sama tidak melindungi bila HP hilang/rusak: sesekali kirim salinannya ke Google Drive atau komputer lewat tombol di atas. Kata sandi backup disimpan di perangkat ini (tidak ikut file backup dan tidak ikut sinkronisasi).

Jejak audit

Mencatat siapa, kapan, dan alasan untuk: ubah harga, void, hapus transaksi, hapus barang, stok, impor, pulihkan backup, dan masuk mode Owner. Transaksi yang dihapus tidak hilang: disalin ke Tempat Sampah dan bisa dipulihkan.
